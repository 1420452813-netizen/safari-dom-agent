Safari DOM Agent — 首次使用说明
=================================================

这是给其他同学用的「自包含版」，不需要装 Python、不需要 pip、不需要编译，
双击就能用。你只需要做下面几步。


一、首次打开（解除 macOS 拦截）
-------------------------------------------------
1. 把 TronClass.app 放到任意位置（建议「应用程序」文件夹）。
2. 双击打开。如果弹出「无法验证开发者 / 已损坏」：
   - 方法 A：系统设置 → 隐私与安全性 → 下方点「仍要打开」。
   - 方法 B：打开终端，执行（把路径换成你的实际路径）：
       xattr -cr /Applications/TronClass.app
   然后重新双击打开即可。


二、填入你自己的 API Key
-------------------------------------------------
本工具用「智谱 GLM-4-Flash」判题，需要你自己的 API Key（免费额度够用）。
1. 打开 https://open.bigmodel.cn/ 注册并登录。
2. 进入「API 密钥」→ 新建一个 Key，复制下来。
3. 打开 TronClass.app，在「智谱 GLM-4-Flash API Key」框里粘贴，点「保存」。
   （Key 只存在你自己电脑的 ~/.tronclass/config.json，不会上传给任何人。）

   如果你已有其他兼容平台的 Key，当前分发版固定走智谱通道，请用智谱的 Key。


三、准备受测页面
-------------------------------------------------
1. 用 Safari 打开目标站点的受测页面，确认题项已加载、处于可回填状态。
   （必须 Safari，不支持 Chrome/Edge；且要登录了你自己的账号。）
2. 回到 TronClass.app，点「刷新自检」，三行应全部变绿：
   - Safari 受测页面检测：已在运行
   - DOMRunner 自动化通道：通道就绪
   - 内置推理执行引擎：内置就绪 (Mach-O)

   若「DOMRunner 自动化通道」不绿 / 运行时提示授权：
   首次运行会把执行通道装到你自己的用户目录（~/Library/Application Support/TronClass/），
   随后系统会弹出「DOMRunner 想要控制 Safari」，点「允许」即可（只需一次，之后全自动）。
   若没弹窗，去 系统设置 → 隐私与安全性 → 自动化，给 DOMRunner 勾上 Safari。
   最终提交用到真实鼠标点击，系统还会请求「辅助功能」和「屏幕录制」权限，按提示允许即可。


四、开始执行
-------------------------------------------------
- 极速整卷回填（全自动）：默认模式。勾选「回填完成后自动点击【提交】」会自动提交
  （⚠️ 提交不可逆，自动提交前请确认判定结果无误）；不勾则只回填、保留页面给你人工复核。
- 逐题复核模式：只勾选判定结果、不提交，便于你自己核对后再手动交。

点「一键开始执行流水线」，下方日志会实时滚动：
   读题 → 并发判题 → 回填选项 →（最终提交）
完成后回到 Safari 核对执行结果。


五、常见问题
-------------------------------------------------
Q：提示「请先填写并保存 API Key」？
A：回到第二步，粘贴并点「保存」。

Q：自检里「内置推理执行引擎」不绿？
A：app 不完整，重新解压一份 TronClass.app。

Q：判题全是空 / 报错？
A：检查网络是否通畅、Key 是否填对、是否选了智谱 glm-4-flash。

Q：最终提交没反应 / 点了没提交？
A：最终提交需要「辅助功能」和「屏幕录制」权限，且 Safari 必须处于最前台；
   去系统设置 → 隐私与安全性 给 TronClass 勾上这两项，再试一次。

Q：这是不是只能用于某一个平台？
A：页面适配信息单独存放在 ~/.tronclass/profile.json（题容器、提交按钮、确认弹窗等选择器），
   默认适配单选/多选/判断/填空四类结构；换平台时改 profile 即可，不用改程序。


六、隐私说明
-------------------------------------------------
- 你的 API Key 仅保存在本机 ~/.tronclass/config.json。
- 题项内容会发送给智谱大模型用于判题，不会保存到其他地方。
- 本工具只在你自己的 Safari 受测页面上自动回填，不影响他人。
